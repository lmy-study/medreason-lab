# MedReasonLab

A workspace for medical vision-language reinforcement learning and a separate medical agent-swarm project.

- [`medvlm-rl/`](medvlm-rl/README.md): Qwen3-VL-2B medical post-training and checkpoint evaluation (restructured in this phase).
- `medix-agent-swarm/`: original separate agent code, intentionally unchanged.
- `config.py`: original root configuration, intentionally retained for compatibility.

See the subproject README and `UPSTREAM.md` before installing or citing the training implementation.
